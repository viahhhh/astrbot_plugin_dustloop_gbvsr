# AstrBot 插件：Dustloop GBVSR 帧数查询

查询 [Dustloop Wiki](https://www.dustloop.com/w/GBVSR) 上《Granblue Fantasy Versus: Rising》全部角色的帧数表数据与招式图片。

## 功能

- 查询任意角色的任意招式：伤害、防御方式、发生/持续/硬直帧数、被防/命中/打康的有利不利帧、攻击等级、无敌时间、备注
- 自动返回招式的**判定框图片**（攻击框/受击框，wiki 的 hitboxes 字段），多段判定按帧数顺序全部返回，并附判定框说明（如 Frame 8 / Frame 9~11）；没有判定框图的招式不发图
- 支持中文角色名与社区俗称（格兰、奶刀、豆丁、飞哥、巴布……）
- **注册了 LLM 工具 `query_gbvsr_move`**：开启函数调用后无需记指令，直接自然语言提问，大模型会自动调用插件（效果类似 MCP）
- 数据缓存 1 小时，不会每次查询都打 wiki

## 两种使用方式

### 方式一：自然语言（推荐，效果类似 MCP）

插件向大模型注册了工具 `query_gbvsr_move`，直接聊天即可：

```
你：格兰的5L发生几帧？被防有利吗？
你：奶刀的623H是什么性能
你：列出姬塔的全部必杀技
```

大模型会自动提取角色名和招式并调用插件，帧数数据由模型整理后回复，招式图片会作为额外消息直接发到会话里。

**前提条件**（缺一不可）：
1. 你用的模型本身支持函数调用/工具调用（function calling）。DeepSeek-V3、GPT-4o、Qwen 系列等都支持
2. AstrBot 管理面板 → 服务提供商 → 编辑你用的模型 → 确认开启了"函数调用"（部分版本叫"工具调用"）
3. 如果模型回答"我无法查询"而根本没调用工具，检查上面两点；也可以发 `/tool` 类指令或看 AstrBot 日志确认工具是否被触发

### 方式二：指令（不依赖函数调用，永远可用）

## 安装

方式一（推荐）：把整个 `astrbot_plugin_dustloop_gbvsr` 文件夹复制到服务器的 `AstrBot/data/plugins/` 目录下，重启 AstrBot。

方式二：AstrBot 管理面板 → 插件管理 → 安装插件 → 上传 zip 压缩包。

## 配置

AstrBot 管理面板 → 插件管理 → 找到本插件 → 配置：

| 选项 | 默认 | 说明 |
|---|---|---|
| `compress_images` | 开启 | 开启时将判定框图下载后压缩为最长边 480px 的 JPEG（手机 QQ 对大分辨率透明 PNG 支持差，压缩后加载更稳）；关闭则直接发送 wiki 原图直链，不经过本地处理 |
| `strip_markdown` | 开启 | 开启时把大模型回复里的 Markdown 语法（`**加粗**`、`# 标题`、列表、表格等）在发送到 QQ 前转成纯文本；关闭则原样发送模型输出 |

## 指令

| 指令 | 说明 |
|---|---|
| `/dustloop <角色> [招式]` | 查询招式（别名：`/gbvsr`、`/帧数`） |
| `/角色列表` | 查看全部可查询角色 |

示例：

```
/dustloop 格兰 5L        → 同时返回 c.L（近身站轻拳）和 f.L（远身站轻拳）
/dustloop 格兰 236L      → L Reginleiv 的帧数 + 图片
/dustloop 奶刀 236236U   → 娜露梅超必杀
/dustloop 格兰 Catastrophe
/帧数 格兰               → 列出格兰全部 49 条招式
```

## 招式写法说明

- GBVSR 的站拳脚没有 `5L/5M/5H`，而是分 `c.L`（近身）与 `f.L`（远身）。输入 `5L` 会自动把两条都返回。
- 蹲拳脚直接写 `2L/2M/2H/2U`，跳拳脚写 `j.L/j.M/j.H/j.U`。
- 必杀技用指令（`236L`、`623H`）或英文名（`Rising Sword`）都可以，大小写不敏感，支持模糊匹配。

## 数据来源与说明

- 数据来自 Dustloop 的 MediaWiki Cargo 接口（表 `MoveData_GBVSR`），帧数随游戏版本更新，以 wiki 页面标注的版本为准。
- 插件目录里的 `test_logic.py` 是独立验证脚本（不依赖 AstrBot），可用 `python3 test_logic.py` 直接测试数据抓取是否正常。
